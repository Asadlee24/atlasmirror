# AtlasMirror Visual & Brand System

AtlasMirror strictly complies with the [Logos Brand Guidelines](https://guide.logos.co/).

---

## Core Brand Principles

1. **Content Over Decoration**: The interface exists to facilitate the verified distribution of geospatial data, not to showcase graphic design gimmicks.
2. **Utility Over Trendy Aesthetics**: High clarity, high density, and immediate legibility supersede decorative styling.
3. **Accessible & Sober**: Accessible color contrast, clear typographic hierarchy, and logical keyboard navigation.
4. **Deliberate & Minimalist**: Every element serves a direct functional purpose.

---

## Color Palette

| Name | Hex Value | Usage |
|---|---|---|
| **Logos Black** | `#000000` | Primary backgrounds (dark theme), primary text (light theme) |
| **Logos White** | `#FFFFFF` | Primary text (dark theme), primary backgrounds (light theme) |
| **Neutral Grey Dark** | `#1A1A1A` | Borders, subtle dividers, inactive panels |
| **Neutral Grey Mid** | `#333333` | Secondary text, inactive badges |
| **Neutral Grey Light** | `#E5E5E5` | Light mode borders and dividers |
| **Functional Blue** | `#0066CC` | Interactive hyperlinks and focal actions only |

### Strict Prohibitions

- **NO** purple Web3 gradients.
- **NO** glowing crypto neon cards.
- **NO** frosted glassmorphism (`backdrop-filter: blur()`).
- **NO** oversized rounded SaaS cards (border-radius > 6px).
- **NO** decorative cryptocurrency token charts.
- **NO** gratuitous animations (animations are strictly limited to progress meters and state transitions).

---

## Typography & Monospace Conventions

- **System Sans-Serif**: Used for general UI copy, headers, labels, and descriptions (`Inter`, `system-ui`, `-apple-system`, `sans-serif`).
- **Monospaced Font**: Used strictly for cryptographic and technical identifiers:
  - Storage CIDs (e.g. `bafybeic7vj2k...`)
  - MD5 / SHA256 Checksums (e.g. `378df25f824177ebcbe9aa11d88bbd6b`)
  - LEZ Program IDs and Transaction Hashes
  - Version dates and file paths
